# Controllo delle immagini di Link (ChatGPT) · 2 novembre 2026

Link ha preparato le 16 immagini che mancavano, nella cartella `Orbis_immagini` sul computer di Olivia. Per ogni creatura ha lasciato l'immagine, il prompt migliorato, le foto usate come riferimento e un file con il confronto e le fonti.

Claude ha guardato ogni immagine accanto alla descrizione scientifica della specie e, dove c'erano, alle foto di riferimento. Risultato: 13 illustrazioni entrano nell'app così come sono. Per le altre 3 creature, tra i riferimenti di Link c'era una foto vera con licenza libera, ed è stata usata quella al posto dell'illustrazione.
