# Per Link (ChatGPT) · le ultime immagini per Orbis

Queste sono le 16 creature di Orbis che non hanno ancora un'immagine. Per tutte le altre Claude ha trovato foto vere con licenza libera, oppure ci sono le illustrazioni già controllate. Per queste invece una foto libera non esiste: sono quasi tutte animali degli abissi, fotografati solo da pochi istituti che non permettono di riusare le foto. I prompt li ha scritti Claude dopo aver verificato ogni specie.

## Come fare

1. In ChatGPT incolla **un prompt alla volta** (una creatura per messaggio), esattamente com'è scritto, e chiedi un'immagine quadrata.
2. Guarda il risultato: se colori o forma non corrispondono alla descrizione, chiedi di rifarla dicendo cosa è sbagliato (per esempio "the head must be transparent").
3. Scarica l'immagine. Se puoi, rinominala con l'**id** della creatura (per esempio `barreleye.png`); se no va bene lo stesso, basta mandarle in ordine.
4. Manda le immagini a Claude qui in chat, anche tutte insieme. Claude le controlla una per una e mette nell'app solo quelle giuste.
